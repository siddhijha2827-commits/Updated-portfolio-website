# Siddhi Jha | Personal Portfolio

A personal portfolio website built with HTML and CSS to introduce me, highlight my education and technical skills, showcase projects, and share links to my professional profiles.

## Features
- Home and introduction
- Education and About Me
- Technical skills
- Projects showcase
- LinkedIn and GitHub links
- Responsive layout
- Smooth navigation

## Built With
- HTML5
- CSS3

## Project Structure
```text
portfolio/
├── index.html
├── style.css
├── profile.jpg
└── README.md
```

## Run Locally
1. Keep the HTML, CSS, and profile image in the same folder.
2. Ensure the filenames match the paths used in the HTML.
3. Open `index.html` in your browser.
